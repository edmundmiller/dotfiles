# oxlint-plugin-jev

Opt-in TypeSafe Jev lint, isolated from repository anti-slop Oxlint 1.78.0.
Keep `oxlint` and `oxlint-plugin-jev` pins aligned in `package.json`. Refresh
`package-lock.json` with `npm install` in this directory. Edit `rules.json` to
add English yes/no rules. Do not put `TYPESAFE_API_KEY` in Nix. Docs:
[oxlint](../../docs/agents/oxlint.md).
