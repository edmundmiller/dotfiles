# Beads issue tracker

This repository tracks issues with `br`
([Dicklesworthstone/beads_rust](https://github.com/Dicklesworthstone/beads_rust)).
`bd` is retired in this setup and must not be used; the zsh shim returns 127.

Common commands:

```bash
br ready
br show <issue-id>
br create "Title" --type task --priority 2
br sync --import-only
br sync --flush-only
```

- Shared issue state is `.beads/issues.jsonl`; SQLite databases, locks,
  recovery files, and history backups are regenerated by `br` and ignored by git.
- Close an issue with `br close <id> --reason <reason>` only after every
  acceptance criterion has fresh evidence and the work is landed.
- Every Herdr downstream patch entry must reference an open bead; close the
  bead only after removing the patch and verifying the affected package.
